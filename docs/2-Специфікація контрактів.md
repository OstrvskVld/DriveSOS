# 2-Специфікація контрактів

DriveSOS має REST API v1 у форматі JSON із 17 ендпоінтів та WebSocket-канал для подій у реальному часі. Базова адреса — `/api/v1`, авторизація — `Authorization: Bearer <JWT>`.

## Загальні правила

- `Content-Type: application/json`, кодування UTF-8.
- Дата і час — ISO 8601 в UTC (`2026-11-26T14:05:00Z`).
- Грошові суми — рядок десяткового числа та `currency` (`"850.00"`, `"UAH"`), щоб уникнути похибок float.
- `POST /sos-requests` і `POST /sos-requests/{id}/payments` вимагають заголовок `Idempotency-Key` (UUID): повторний запит із тим самим ключем повертає першу відповідь.
- Списки пагінуються параметрами `page` (від 1) та `size` (до 50).
- Усі помилки мають один формат:

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Request body is invalid",
    "details": [{ "field": "location.lat", "issue": "must be between -90 and 90" }],
    "traceId": "9f1c2a7e-3b4d-4c55-a1e2-0d6f7b8c9a10"
  }
}
```

## POST /sos-requests

Водій створює заявку; сервер рахує `priceEstimate` і одразу переводить заявку в `searching`.

Запит:

```json
{
  "vehicleId": 17,
  "serviceType": "tow",
  "location": { "lat": 49.839683, "lng": 24.029717, "address": "вул. Городоцька, 120, Львів" },
  "description": "Не заводиться, потрібен евакуатор до СТО"
}
```

| Поле | Тип | Обов'язкове | Правило |
| --- | --- | --- | --- |
| `vehicleId` | integer | так | Авто належить поточному водію |
| `serviceType` | string | так | Одне з: `tow`, `tire`, `fuel`, `battery`, `unlock` |
| `location.lat` | number | так | −90…90 |
| `location.lng` | number | так | −180…180 |
| `location.address` | string | ні | До 255 символів |
| `description` | string | ні | До 1000 символів |

Відповідь `201 Created`, заголовок `Location: /api/v1/sos-requests/1042`:

```json
{
  "id": 1042,
  "status": "searching",
  "serviceType": "tow",
  "vehicleId": 17,
  "location": { "lat": 49.839683, "lng": 24.029717, "address": "вул. Городоцька, 120, Львів" },
  "priceEstimate": { "amount": "850.00", "currency": "UAH" },
  "provider": null,
  "createdAt": "2026-11-26T14:05:00Z"
}
```

Помилки: `400 VALIDATION_ERROR`, `401 UNAUTHORIZED`, `403 FORBIDDEN` (чуже авто), `409 ACTIVE_REQUEST_EXISTS` (у водія вже є активна заявка).

## POST /sos-requests/{id}/accept

Виконавець у статусі online, який надає цю послугу, приймає заявку. Призначення атомарне: `UPDATE … WHERE status = 'searching'`, тому другий виконавець отримає 409.

Запит:

```json
{ "etaMinutes": 25 }
```

Відповідь `200 OK`:

```json
{
  "id": 1042,
  "status": "assigned",
  "provider": { "id": 8, "name": "Евакуатор 24/7", "phone": "+380671234567", "rating": 4.8 },
  "etaMinutes": 25,
  "assignedAt": "2026-11-26T14:07:12Z"
}
```

Помилки: `403 FORBIDDEN` (не provider або не надає цієї послуги), `404 NOT_FOUND`, `409 REQUEST_ALREADY_ASSIGNED`.

## PATCH /sos-requests/{id}/status

Виконавець рухає заявку по статусах; кожен перехід пишеться в `request_status_history`.

```json
{ "status": "completed", "priceFinal": { "amount": "920.00", "currency": "UAH" } }
```

| З статусу | Дозволений перехід | Хто |
| --- | --- | --- |
| `created` | `searching` | система |
| `searching` | `assigned` (через `/accept`), `cancelled` | provider, driver, система (тайм-аут) |
| `assigned` | `en_route`, `cancelled` | provider, driver |
| `en_route` | `in_progress`, `cancelled` | provider, driver |
| `in_progress` | `completed` (обов'язковий `priceFinal`) | provider |
| `completed`, `cancelled` | — (кінцеві) | — |

Помилки: `403 FORBIDDEN` (заявка не цього виконавця), `409 INVALID_STATUS_TRANSITION`, `400 VALIDATION_ERROR` (немає `priceFinal` для `completed`).

## POST /sos-requests/{id}/payments

Доступно лише для заявки в статусі `completed`; сума береться з `priceFinal`, клієнт її не передає.

```json
{ "method": "card" }
```

Відповідь `201 Created`:

```json
{
  "paymentId": 553,
  "status": "pending",
  "amount": { "amount": "920.00", "currency": "UAH" },
  "checkoutUrl": "https://pay.example/checkout/abc123"
}
```

Для `method: "cash"` повертається `status: "pending"` без `checkoutUrl`; виконавець підтверджує отримання готівки через `POST /payments/{id}/confirm-cash`. Після `failed` повторний запит оновлює той самий запис `payments` (`request_id` унікальний), а не створює новий. Помилки: `409 REQUEST_NOT_COMPLETED`, `409 ALREADY_PAID`.

## POST /sos-requests/{id}/review

```json
{ "rating": 5, "comment": "Приїхали за 20 хвилин, все добре" }
```

Відповідь `201 Created` повертає відгук із `id` та `createdAt`; сервер перераховує `providers.rating_avg`. Помилки: `400 VALIDATION_ERROR` (`rating` поза 1…5), `409 REQUEST_NOT_COMPLETED`, `409 REVIEW_EXISTS`.

## Події WebSocket

Канал `wss://<host>/api/v1/ws?token=<JWT>`; кожна подія — `{ "event": "<назва>", "data": { … } }`.

| Подія | Отримувач | Коли |
| --- | --- | --- |
| `request.offered` | online-виконавці в радіусі пошуку | Заявка перейшла в `searching` |
| `request.assigned` | водій | Виконавець прийняв заявку |
| `request.status_changed` | водій, виконавець | Будь-яка зміна статусу |
| `provider.location` | водій | Кожні 5 с у статусі `en_route` |
| `payment.updated` | водій, виконавець | Оплата `paid` або `failed` |

## Коди помилок

| HTTP | `code` | Коли |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | Некоректне тіло або параметри |
| 401 | `UNAUTHORIZED` | Немає або прострочений JWT; невалідний підпис вебхука |
| 403 | `FORBIDDEN` | Роль або власник не збігається |
| 404 | `NOT_FOUND` | Ресурсу не існує або він недоступний |
| 409 | `ACTIVE_REQUEST_EXISTS` | У водія вже є активна заявка |
| 409 | `REQUEST_ALREADY_ASSIGNED` | Заявку вже прийняв інший виконавець |
| 409 | `INVALID_STATUS_TRANSITION` | Перехід не дозволений таблицею статусів |
| 409 | `REQUEST_NOT_COMPLETED` | Оплата чи відгук до статусу `completed` |
| 409 | `ALREADY_PAID`, `REVIEW_EXISTS` | Повторна оплата чи відгук |
| 429 | `RATE_LIMITED` | Перевищено ліміт запитів |
| 500 | `INTERNAL_ERROR` | Непередбачена помилка сервера |
